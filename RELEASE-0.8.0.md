22 797 278 байт, 300 045 строк, 169 миров показов; школьная сборка

**Мера релиза — удержанный ключ.** `datasets/HOLDOUT-KEY.tsv`: 1 268 вопросов,
которых свод НЕ показывал — формы и акты домов с числами и словами вне их

глубины 0 / 1 / 2+; строк, прожитых сводом, — ноль (сверка со всеми 169 мирами).
Ключ есть функция домов и объявленных чисел: `scripts/holdout_key.py` переписывает
его на каждой точке, `scripts/holdout_run.sh STATE OUTDIR [N]` ставит его читателю,
судья `scripts/sweep_self.py` меряет значением (конец ответа, последнее число,
составная единица; вопросы «почему» — вне значения).

**Что вошло в свод восьмой точки.**

- **Держания без глагола** (новый дом, 3 192 показа, девять языков) — первый показ
  «только рамками»: держание, возраст, двое (вопрос о втором носителе), «нет … —
  ноль». Ни акта, ни леджера: ответ есть число истории, сказанное обратно.
- **Рамки сравнения** (новый дом, 3 456 показов, девять языков) — больше на N,
  меньше на N, вдвое / втрое, «на сколько больше»; знак леджера есть дыра, и
  рамка «больше» с минусом — ложь по знаку.
- **Дом историй SVAMP** 1 568 → 4 954 показа: акты полосы на семи языках, близнецы
  имя/местоимение, ось знаков, доли историй с цепочкой шагов, возраст с именем,
  «сколько всего вещей» над тремя товарами, владение полным предложением
  (own / hold / keep и восемь языков), поссессивы и объектные местоимения.
- **Языковые пакеты**: правило счёта fr / es / it / pt / nl — единственное только
  при ровно 1 (несли русское правило: «11 an», «21 año», «21 anni»); польское
  правило исправлено раньше в тот же день.
- **Числовой ряд** 5 004 → 5 256 (ряды до восьми), буквы получили имена
  («как читается буква b? буква b читается как бэ»), мир LaTeX — бином на всех
  парах букв.

**Законы и приборы, поддерживающие меру.**

- потолок повтора строки LAW = 2 на мир (свод похудел на 4,4 МБ без потери показов);
- порядок ветвей альтернаций выводится из содержания (71 место): тексты образцов
  палаты побайтово устойчивы между процессами;
- постоянный кэш образцов — палата строится за 1,7 с вместо 22;
- ворота записи параллельны и уступают нагрузке машины;
- досягаемость суда (`scripts/court_reach.py`): суд, выросший головами, пересуживает
  все миры до посадки;
- «свод спрашивает себя» (`scripts/sweep_self.py`) — мера чтения по классам глубины
  и по причинам немоты читателя.
