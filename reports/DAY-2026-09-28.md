- ИСХОДЫ — род: прогон одним приказом («run the Python tests») на проекте в том состоянии, какое держит мир (правка,
  давшая состояние, страницей не названа), — всякий исход, какого прогон на объявленном проекте не показывал ни у одного
  бегуна: Python — провал («5 of 8 tests passed: 8 − 3 = 5, 3 failed.», «6 of 8 …», «7 of 8 …», «8 of 9 …»), ошибка
  теста (unittest «errors»: «7 of 8 tests passed: 8 − 1 = 7, 1 error.», «5 of 8 …, 3 errors.»), провал вместе с ошибкой
  («3 of 8 tests passed: 8 − 4 − 1 = 3, 4 failed and 1 error.» — леджер вычитает всякое число строки FAILED, как бегун
  его написал, и называет вычтенное словом отказа: у всякой формы место вычитаемого одного рода — слово ведущего);
  прогон без тестов — пакет Web (unittest ищет тесты в папке web, их нет: «NO TESTS RAN», код 5; «no tests ran. the run
  ended with an error.»); Gauge — провал полного прогона крейта («4 tests passed, 1 failed: 2 + 2 = 4»). На всякое
  состояние — три плоских страницы (прогонов «до» 1, 2, 5) и вежливая. Состояния — `repoworld.СОСТОЯНИЯ_ИСХОДОВ` (ошибка,
  три ошибки, два провала, провал с ошибкой — дважды, девятый тест) и прежние `ПРАВКИ_ПРОЕКТА`; отчёты сняты сервером
  мира процесса ядра (М-2069: пути от дома). Строка падения Python — одна дверь: 18 прежних страниц python-fail (план

- Суд: прогон одним приказом судится против всякого объявленного состояния — отчёт на странице обязан быть отчётом одного из

- Чего в роде нет, названо: успех cargo — форма успеха Python («all # tests passed»), место её исхода ядро купило числом
