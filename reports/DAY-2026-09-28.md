    КАНОНИЧЕСКИМ.

- РЕГИСТРЫ (дверь `toolacts.РЕЧЬ[…]["регистры"]`, {inf} акта): косвенный двери («we need to …», «нужно …», «man sollte …»,
  «il faut …» — дом toolrepo его прежде не показывал), нужда первым лицом («i need to …», «мне нужно …», «ich muss …»,
  «je dois …», «necesito …», «ho bisogno di …», «preciso de …», «ik moet …», «muszę …»), желание («i would like to …»,
  «я хочу …», «ich möchte …», «je voudrais …», «quiero …», «vorrei …», «queria …», «ik wil graag …», «chcę …») — на
  основах вопросных регистров всех семи актов. Без апострофа (ухо ядра рвёт слово на нём: «I'd», «j'ai besoin») и без
  придаточного со спряжением («хочу, чтобы ты удалил …»).
- ЗАЧИН НУЖДЫ И ЖЕЛАНИЯ ЗНАТЬ (дверь `toolacts.ЗАЧИН`, два вида в конце ряда): «i need to know which file contains …», «мне
  нужно знать, …», «ich möchte wissen, …» — на всех девяти одиночных вопросах.
- СТРАДАТЕЛЬНЫЙ ОБОРОТ ИЛИ ДОЛЖЕНСТВОВАНИЕ С ОБЪЕКТОМ ВПЕРЕДИ (дверь `toolacts.СТРАДАТЕЛЬНЫЙ`, шаблон на акт и голос): «the
  file F should be deleted», «файл F нужно удалить», «die Datei F muss gelöscht werden», «le fichier F doit être supprimé»,
  «el archivo F debe eliminarse», «il file F va eliminato», «o ficheiro F tem de ser eliminado», «het bestand F moet
  verwijderd worden», «plik F trzeba usunąć»; где род или падеж объекта менялся бы с наполнителем (de «den Text», it «la
  parola / il testo», pt «a palavra / o texto» у замены) — безличное долженствование с объектом в падеже двери («man muss
  …», «si deve sostituire …», «tem de se substituir …»).
- СОСТАВНЫЕ СТРАНИЦЫ «конструкция × синоним × голый путь» (дверь `toolacts.СИНОНИМЫ_ИНФ` — первый синоним акта
