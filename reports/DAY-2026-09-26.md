## Семьи конструкций — формы, общие для любых слов (ветка constructions поверх paraphrase)

Заказ ведущего: семьи правок шире и роды, на каких AGENT-K ещё нем, — формы, общие для любых слов: не фразы ключа и
без его наполнителей; всякая — с ходом мира, четыре основы на язык, два вида актов, где возможно. Мера обобщения —
отложенный ключ коллегии, не AGENT-K v0: фраз v0 в своде нет (длиннейший общий ряд ≤ 6 слов).

    КОНСТРУКЦИЯ — РАМКА ДЛЯ ЛЮБЫХ СЛОВ, А НЕ ФРАЗА: ход мира и итог — те же клетки, что у канонической формы.

Конструкции (9 языков, по 4 основы на язык; итог организма — клетки хода мира, как у канонической формы):
- файл со словом глаголом-синонимом: «which file mentions W?», «где встречается W?», «welche Datei erwähnt W?» — find;
- номер строки: «on which line of F does W appear?», «на какой строке файла F стоит W?» — find;
- текст строки: «what does the first / second / last line of F say?», «какая первая строка в файле F?»; «what is
  written at the end of F?», «что написано в конце файла F?» (дыра — лишь файл: слово выбора в вопросе не стоит);
  «read line N of F.», «show line N of F.», «прочитай строку N файла F.», «покажи строку N файла F.» — lines;
- значение ключа без слова «ключ»: «what is the value of k in F?», «какое значение k в файле F?» — find; и «что
  файл с именем F говорит о k?» («a file called F» у вопросов о ключе — семья `назв` стоит и у вопросов);
- дописывание в конец: «at the end of the file F, append S», «в конец файла F допиши S» (место впереди, 9 языков);
  «add S at the end of the file F», «добавь в конец файла F S» (синоним глагола при месте в конце, 9 языков);
  «append S at the end of the file F», «допиши в конец файла F S», «ergänze S am Ende der Datei F» (место внутри
  приказа — en, ru, de: у прочих каноническое «в конец» уже стоит там же) — line;
- перенос с местом впереди: «в папку D перенеси файл F», «in den Ordner D verschiebe die Datei F», «do folderu D
  przenieś plik F» — ru, de, pl: у прочих языков место назначения перед повелением неестественно;
- четвёртая вопросная просьба: «would you …?», «а можешь …?», «kannst du mal …?», «est-ce que tu peux … ?»,
  «¿puedes por favor …?», «puoi gentilmente …?», «podes por favor …?», «kan je …?», «czy możesz proszę …?» — 6 видов
  (create, delete, line, move, replace, run); зачины объявлены домом пары (`asking`), пакеты не тронуты;
- план с вопросом о несомом месте: «rename F to G, then let me know how many lines it has», «…, затем скажи, сколько в
  нём строк» — первый акт move (переименование, перенос) или line, второй — lines там, куда строка path первого хода
  положила объект; предложение называет путь, какой определяет приказ; основы — где число строк разводится с прочими
  мерами хода. Английская форма — соседняя: у первой пробы длиннейший общий ряд с ключом AGENT-K вышел 8 слов (> 6,
  мера счётом `genesis_key_overlap`), у «let me know» — 5.

Семьи правок по видам актов мира: место впереди — 5 (create, delete, line, move, replace); вежливая и три вопросные

Роды (9 языков, по 4 основы на форму и язык — первые из объявления мира, какие разводят источники; ход мира — после
всякого акта):
- план из трёх актов: «create the file X, then append S to it, then let me know how many lines it has» — первый акт
  create, move (переименование, перенос) или replace; второй дописывает строку туда, куда первый положил объект;
  третий — «сколько строк» там же или прогон тестов;
- условный приказ на ходе мира: «if the file F exists, append S to it, otherwise create it», «if the file F exists,
  delete it», «if the file F contains the text A, replace it with B» — мир проверяет условие (read файла, find текста),
  итог проверки называет исход («the file F exists», «the file F does not exist»), акт ветки — вторым ходом мира;
  ветка без акта — «the condition is not met, the act is not performed» (хвост условия у двери хода); обе ветки на
  всякой форме, условие впереди и после («… if it exists»);
- «все файлы папки, кроме n»: «delete all files in the folder D except n», «move all files from the folder D to the
  folder E except n» и правка отрицанием «…, but don't touch n» — мир читает папку (list), итог называет её записи,
  акт идёт на всякий файл, кроме названного;
- два объекта в одном приказе: «delete the files f and q», «create …», «move … to the folder D», «append S to the
  files f and q» — правка плана из двух актов «…, then …» (то же предложение, тот же ход мира);
- ссылка на прошлый шаг без местоимения: «…, then append S to this file / to the same file», «…, then delete this
  file», «…, then let me know how many lines this file has» — правка плана с местоимением.
Семьи правок по видам первого хода мира: «и» — 4 (create, delete, line, move); «ссылка» — 3 (create, line, move);
