## Планы одного приказа: «into it», «as its only line», «its line count», «which file it's in», союз «and» (ветка plans поверх contr, наряд ведущего (f); рука Opus под 6c)

- «its line count» — второй вопрос плана с местоимением: «rename the file F to G, then tell me its line count», «…,
  затем сообщи, каково число строк в нём»; дверь ССЫЛКА, вид «число»; 108 страниц.
- «which file it's in» — форма вопроса В_КАКОМ, не род: «look for the text "x" and tell me which file it's in» (один
  ход мира find, ответ вопроса); «it's» — лишь en, у ru, de, nl — «это», «das», «dat»; 36 страниц.
- «into it» — вид «в_него» двери ССЫЛКА: глаголом акта, где голос так говорит (es «añade … en él», pt «acrescenta …
  nele», nl «zet … erin»), и синонимом, где голосу он нужен (en «put / write … into it», de «schreib … hinein», «füge …
  ein»). Правило дома «местоимение держит глагол акта» ослаблено словом ведущего для приказа пользователя: новый вид
  сверяет глагол с рядом синонимов акта (`toolacts.СИНОНИМЫ`), прежние виды — с глаголом акта; организм говорит
  канонически.
- «as its only line» — план create + line двумя формами: «create the file F, then add "x" as its only line» и «create
  the file F and add "x" as its only line» (у nl — одной формой «en … daarna»); итог второго акта «contains 1 line: 0 + 1
  = 1».
- СОЮЗ «AND» между двумя актами — правка готовой страницы (`союзом`): правка кода + прогон, перенос + удаление; союз
  ставится лишь там, где «и» голоса — не связка его канонического плана (у nl «en … daarna» и есть связка). Число «and»
  подобрано по худшему счёту связки (все новые «and» — соперницы «then»): запас en 60, ru 60, de 52, fr 30, es 56, it
  62, pt 56, pl 11, nl 3 (вариант в 712 страниц в худшем счёте ронял связку у pl и fr и сужен до 328).
Мир toolrepo 14 738 страниц: прежние 14 410 байт в байт и 328 новых. Перепись рамок (варки VRG — без планов, VRF — с
ними): из 9 323 общих показов переходов 0; связки куплены все девять и окрепли — свидетелей then 217 → 249, затем 217 →
233, dann 217 → 249, luego 210 → 234, poi 221 → 237, puis 126 → 142, depois 193 → 217, potem 104 → 112, соперниц столько
же. Новые плановые формы — NAMED: «its line count» 60 из 68, «into it» 48 из 56, «as its only line» с «, then» 28 из 36,

ядра (рука joins2), дом «and» показал.

## Классы томографа ведущего: артикль, конец файла, «count» у вхождений, вопросы о тех же актах, винительный слова строки (ветка tomograph поверх plans; руки Opus под 6c)

Томограф немых строк ключа разработки (ведущий называет классы, строк не передаёт) — общие классы вариаций, каких дом не
показывал. Перепись глаголов по актам (мир plans): форм-глаголов с одной страницей 0; дыра одна — «count» у счёта
вхождений (у акта find ни страницы).
- (h1) АРТИКЛЬ — неопределённый вместо определённого: «create a file plan.md», «append a line "x" to the file F» (en,
  de, fr, es, it, pt, nl; ru и pl артикля не знают) — вариант в конце ряда двери ОБЪЕКТЫ, прежние циклы его не берут;
  КОНЕЦ ФАЙЛА голым именем: «append "x" to the end of F», «add the line "x" to the end of F» (дверь КОНЕЦ); «COUNT» У
  ВХОЖДЕНИЙ: «count the occurrences of the word "x" in the repository», «count how many times … occurs in the folder D»
  (en, ru, pl — обе формы; прочие — вид голоса «сколько раз»). 224 страницы.
- (h2) ВОПРОСЫ О ТОМ ЖЕ АКТЕ, ответ значением: «do the Python tests pass?» (новый род ТЕСТЫ_ЛИ: прогон, «yes / no» по
  коду выхода мира), «how many times does the word "x" occur in the file F?» (РАЗ, форма «файл»); «does the file F
  exist?» не строится — ответ мира «да/нет», акта такого в доме нет (слово ведущего). ВИНИТЕЛЬНЫЙ СЛОВА СТРОКИ:
  «прочитай первую строку F», «покажи последнюю строку файла F», «выведи вторую строку из файла F» и пары голосов
  («show the last line of the file F») — ряд `выбор_в`. 225 страниц.
