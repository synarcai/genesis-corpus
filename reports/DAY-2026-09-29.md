# ДЕНЬ 29.09.2026: КОД РЕПОЗИТОРИЯ — МИР

## Дом кода `toolcode` (ветка codeworld над main 9d7bfc8; наряд ведущего omega-90 к М-2099, поток П3 продукта ozar)

Дом актов `toolrepo` научил руки агента файлам репозитория: создать, удалить, перенести, дописать, прогнать тесты. Дом
кода — те же руки над КОДОМ того же репозитория: где определено имя, где оно упомянуто, что определяет файл, как
переименовать имя по всему проекту. Физику кода отвечает не корпус: мир кода — языковой сервер самого языка по протоколу
LSP 3.17 (rust-analyzer для Rust, pyright для Python) за мостом ядра `ozar_lsp_world` (ozar-core, ветка omega-codeworld,
коммит 7deaf4691).

    В КОРПУСЕ НЕТ МОДЕЛИ ЯЗЫКА ПРОГРАММИРОВАНИЯ. Определение, упоминания, символы и правка — ответ сервера, снятый однажды;
    дом лишь говорит его голосами. Один источник правды — сервер языка.

- МИР (`tools/codeworld.py`): объявленный проект — тот же `repoworld.ПРОЕКТ` (web/ и tests/ на Python, крейты tally/ и
  gauge/ на Rust), миру кода не заведено ни одного своего файла. Роды — define (строки path line text sort, счёт
  definitions), refs (path line text; references — без определений), symbols (name sort line text), rename (path
  изменённых файлов; occurrences — всякое вхождение, определение тоже). Ход мира — строкой дома актов
  («define half · definitions 1 · path gauge/src/lib.rs · line 4 · text "…" · sort Function»), отказ — «… · refused
  not-there "blink"». Головы хода мира кода внесены в `folderworld.ВИДЫ`: знак языка провод речью страницы не судит.
- СЪЁМКА (`tools/toolcode_capture.py --снять`): проект кладётся в папку, мост поднимает оба сервера, акты чтения идут
  одной сессией (40), всякое переименование — своей сессией на свежей копии (8). Отказ моста io — беда моста, а не
  правда мира: повтор новой сессией, семя с io самопроверка не принимает. После всякой правки на оставленном ею состоянии
  снимаются прогоны, чей код правка тронула (`codeworld.прогоны_затронутые`, прибор съёмки прогонов дома актов через
  сервер мира процесса `ozar_process`) — 9 отчётов. Семя `tools/seeds/toolcode_world.json` несёт версии серверов
  (rust-analyzer 1.97.0-nightly 9838411c, pyright 1.1.414) и отпечаток проекта, актов и команд прогонов
  (cc1e7b90935e1844): смена сервера — новое семя, не правка старого. Без доводов прибор только читает.
- СЛОВО СОРТА — дверь голосов (`toolcode.СОРТ`): сорт протокола (перечень SymbolKind: Function, Method, Class, Module,
  Variable) голос говорит своим словом и согласует причастие («функция half определена», «метод test_name определён»,
  «la fonction … définie», «funkcja … zdefiniowana»).
- РОДЫ ДОМА (девять голосов): где определено имя (вопрос «где», вопрос словом сорта «in which file is the function X?»,
  приказ «find the definition of X»); где имя упомянуто (где, сколько раз, «find the references to X») — счёт references
  леджером и места строками хода по порядку; имя нигде не упомянуто; имени нет (not-there); что определяет файл (вопрос и
  «list the symbols of the file F») — сорт, имя и строка всякого символа по порядку; файл без символов; файла нет;
  переименование (голым именем, словом сорта «rename the function X to Y», «во всём проекте»; регистры прямой, вежливый и
  вопросная просьба) — предложение, «да», ход мира (WorkspaceEdit сервера) и отчёт о числе вхождений и файлах правки; на
  «нет» — чтение «до» (упоминания имени); новое имя уже определено (already-there — переименование не сливает двух
  имён); имени нет.
- ПЛАН ДВУХ МИРОВ (М-2056: акт идёт в мир, какой объявил его род): «rename half to halve, then run the Gauge tests» —
  правку отвечает сервер языка, прогон — мир процесса на проекте, каким его оставила правка; итог прогона — дверью дома
  актов (числа отчёта бегуна, исход по коду выхода, леджер запусков). На «нет» — чтение «до» мира кода, прогон не идёт.

    ПРАВДА МИРА — КАК ЕСТЬ (слово ведущего): после half → halve rust-analyzer не тронул вхождение в doc-комментарии, и
    доктест gauge падает («cannot find function `half` in crate `gauge`»); страница говорит «5 tests passed, 1 failed:
    2 + 3 + 0 = 5. the run ended with an error». Это физика мира, а не ошибка моста; прятать её — ложь дома.

- УСЛОВИЯ РЫНКА М-2013 и РАЗВЕДЕНИЕ ИСТОЧНИКОВ держит самопроверка дома: итог называет всякую дыру приказа; число итога —
  клетка хода, и ни одно прочее число не равно мере хода, какой оно не называет (дверь дома актов `toolrepo._разведено`,
  клетки хода мира кода — по полям его рода); у всякой правленой формы и регистра — прямая каноническая пара того же хода
  мира. Основы разводят источники: строка определения не первая, счёт упоминаний не равен ни одному номеру их строк, у
  файла символов не столько, сколько номер строки какого-либо из них (gauge/src/lib.rs — счёт 4 при символе на строке 4 —
  в вопросах о символах не спрашивается, названо в манифесте).
- СУД (`courts/toolcode_court.py`, мир замкнут): рамки — у сборок дома с метками вместо имени, файла, нового имени, хода
  мира, чисел и перечней; суд сам идёт в семя — ход на странице обязан совпасть с ходом семени байт в байт — и сверяет итог
  с клетками хода: сорт, путь и строку определения, счёт и места упоминаний, символы по порядку, счёт occurrences и файлы
  правки, отказ по имени; у плана — прогон на состоянии после ЭТОЙ правки, запуски «до» + 1, числа итога стоят в отчёте
  бегуна. Чтение отчёта судом вынесено в `tools/runnerread.py` — одно на суды дома актов и дома кода (прежде жило в
  `toolrepo_court`). Подсадки — от дома: числа, леджеры, меры хода, путь, слово сорта сборкой с другим сортом (причастие
  согласовано), перечень в обратном порядке, ход чужого акта, отчёт проекта до правки под планом, «да»/«нет».
