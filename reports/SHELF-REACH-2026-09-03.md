# ОХВАТ ПОЛКИ — сколько знания книг корпус умеет прочесть (03.09.2026)

Вопрос владельца стоит о знании: «сколько процентов знаний извлекается, достижим ли предел». Для ПОКАЗОВ ответ измерен и полон: 281 670 из 281 670 строк читаются судами, слепых нет, зачёт словарём — ноль. Для ПОЛКИ (197 книг, больше миллиона строк: учебники, романы, статьи) ответ иной, и он получен прибором `scripts/shelf_reach.py`.

## Число

Выборка 2 955 предложений, взятых поровну из 197 книг (детерминированно по семени):

| мера | значение |
|---|---|
| прочитаны судами | 46 (1 %) |
| из них названы ложными | 39 |
| не прочитаны | 2 909 |

**Один процент.** И даже эти сорок шесть прочитаны в основном ошибочно: тридцать девять названы ложью судами письма и половин — не потому, что книга лжёт, а потому, что суд показов встретил чужую форму и приложил к ней свою мерку. Это предел судов, а не изъян книг.

## Природа непрочитанного — карта ближайших домов

| доля | природа | чем могло бы судиться |
|---|---|---|
| 36 % | повествование без числа и связки | ничем из нынешнего: это язык, а не форма |
| 20 % | перечисление без числа | дом списков |
| 15 % | число без равенства | дом «число при вещи» |
| 14 % | связка без числа | дом определений |
| 7 % | перечисление с числом | дом списков |
| 3 % | вопрос без ответа рядом | дом пары |
| 0 % | равенство | судится счётом уже сегодня |

## Что это значит

Полка не обязана быть судимой: книга пишется не для суда. Число «один процент» — не долг полки и не изъян корпуса, а **граница между двумя способами знать**. Показы корпуса суть формы с дырами, и суд проверяет их пересчётом. Книга суть язык, и её знание берётся не судом, а РЫНКОМ на стороне организма: формой, купленной из показов и приложенной к прозе.

Отсюда два следствия, оба проверяемые.

1. **Дом, а не суд.** Если строить чтение полки, строить надо дома тех родов, которые в ней часты: списки (27 % с числом и без), «число при вещи» (15 %), определения (14 %). Каждый такой дом даёт форму, которую организм покупает на показах и потом узнаёт в книге — так знание переходит с полки в организм, минуя суд.

2. **Предел измерим заранее.** Тридцать шесть процентов прозы — повествование без числа и связки; для него ни один дом форм не поможет, и его знание доступно лишь тому рынку, который читает язык целиком. Значит потолок «чтения полки домами» лежит около шестидесяти процентов её предложений, и это число названо до постройки, а не после.

Прибор запускается так:

```
python3 scripts/shelf_reach.py --выборка 3000 --семя 1
```
